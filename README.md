# Bank Management System

A console-based Bank Management System built with Python (`bank_project.py`) that simulates core banking operations such as account creation, deposits, withdrawals, and balance inquiries.

## Features

- **Create Account:** Open a new bank account with customer details and an initial deposit.
- **Deposit Funds:** Add money to an existing account with automatic balance updates.
- **Withdraw Funds:** Withdraw money with validation to prevent overdrafts/insufficient balance.
- **Balance Inquiry:** View current account details and available balance.
- **Account Management:** Update account holder details or close an existing account.

## Prerequisites

- Python 3.x installed on your system.
